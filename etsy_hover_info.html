What it shows on hover

Total sales

Rating & reviews

Star rating plus review count, shown exactly as Etsy displays it — nothing invented.

Ships from

Install it in Chrome

6 steps
  1. Download the ZIP above, then unzip it anywhere on your computer.
  2. Open chrome://extensions/ in a new tab.
  3. Turn on Developer mode using the toggle in the top right.
  4. If an older version of this extension is installed, remove or disable it first.
  5. Click Load unpacked and select the extracted etsy-hover-info-v1.5 folder.
  6. Refresh any open Etsy tab, then hover a listing card to see the info.
This extension only reads what Etsy already shows on the page and shop. If a value isn't available, it honestly displays Not found instead of guessing.
